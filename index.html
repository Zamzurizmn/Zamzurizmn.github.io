Featured · 2026350 nm CMOS

Negative-resistance LC oscillator at 433 MHz

A cross-coupled NMOS pair whose negative resistance (−2/gm) cancels the losses of two 10 nH, QL = 20 inductors (rL = 1.36 Ω, RT ≈ 544 Ω) resonating with 6.76 pF across the outputs, biased by a 2.2 mA current-mirror tail. Specification: Vout,pp > 1 V, phase noise < −110 dBc/Hz at 100 kHz and Ibias < 5 mA from 3.3 V.

I sized the devices by hand with gm set to twice the start-up value, then verified the tank (S-parameters), start-up, amplitude and phase noise with tran, PSS and pnoise in Spectre, comparing each result to theory.

ENSEIRB-MATMECA · Feb–Apr 2026C

Mandelbrot deep-zoom engine

A fractal renderer written in pure C that animates a deep zoom into the Mandelbrot set. Each pixel runs the escape-time loop zn+1 = zn2 + c, written out in real and imaginary parts for speed.

A master process splits every frame across four parallel worker processes. A modulo-based phase function maps escape counts to smooth RGB gradients, and the frames are assembled into a high-resolution MP4.

How it connects to microelectronics
  • Parallel by natureEvery pixel is independent, which is why the Mandelbrot set is a classic benchmark for hardware accelerators. Splitting a frame across four workers is the software version of placing several compute cores on one chip.
  • Arithmetic becomes areaOne iteration takes three multiplications (x², y², xy) and a few additions. On an FPGA or ASIC each multiplier is a DSP block or an array of gates, and pipelining them sets the clock frequency and the throughput.
  • Precision costs siliconDeep zooms need more bits to separate neighbouring points. Picking a word length is the same trade-off between accuracy, area and power that sets the resolution of a data converter.
ENSEIRB-MATMECA · Mar–May 2025VHDL · Artix-7

FPGA random number generator (LOTO system)

A fully synchronous digital system on a Xilinx Artix-7 FPGA (Nexys 4 board) that draws six pseudo-random lottery numbers, checks that they are unique (with OK and restart LEDs), and shows them on the 7-segment display.

The hierarchical VHDL design has a clock-management block that produces clock enables, a flip-flop stage for the push button, the draw logic, modulo counters, multiplexers and a binary-to-7-segment transcoder. Every block was verified with testbenches before synthesis, placement and routing in Vivado.

How it connects to microelectronics
  • The digital chip design flowRTL in VHDL, testbench simulation, synthesis, placement, routing and timing checks are the same front-end steps used for a digital ASIC. FPGAs are where that logic is usually prototyped before tape-out.
  • Synchronous design disciplineThe clock-management block generates clock enables (CE_AFFICHAGE, CE_PROCESSING) instead of new clocks, so the whole design stays in one clock domain and static timing analysis holds. Chip designers follow the same rule to close timing.
  • Asynchronous inputs and metastabilityThe push button is not aligned to the clock, so it passes through its own flip-flop block before the draw logic sees it. It is the same problem as reading a comparator output in an ADC or passing data between clock domains.
  • Utilisation is areaUsing 0.37 % of the LUTs is the FPGA version of a small die. On an ASIC, the same logic would be measured in gates and µm².
